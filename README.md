# Employee Management System (Java + SQLite)

A standalone desktop application built using Java Swing and SQLite.

## 🚀 Features
- Add Employee
- Update Employee
- Delete Employee
- Retrieve Employee
- Embedded SQLite database
- Windows EXE packaging using jpackage

## 🛠 Technologies Used
- Java
- Swing (GUI)
- JDBC
- SQLite
- jpackage

## 📂 Project Structure
src/
 └── Employees/
     ├── Main.java
     ├── InsertEmployee.java
     ├── UpdateEmp.java
     ├── DeleteEmp.java
     ├── FetchEmp.java
     └── DatabaseUtil.java

## 📦 How to Run
1. Clone the repository
2. Add SQLite JDBC dependency
3. Run Main.java

## 📌 Highlights
- Dynamic field-level update logic
- Embedded database (No MySQL required)
- Standalone Windows executable
